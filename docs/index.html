Reliability Features

🔑
Idempotency Keys
Same key + same params = same Stripe session. Double-clicks and client retries don't create duplicate subscriptions.
🛡️
Signature Verification
Every webhook payload is verified with constructEvent(). Fake events are rejected with 400.
♻️
Duplicate Event Guard
Stripe delivers at-least-once. Processed event IDs are stored in MongoDB so re-deliveries are skipped silently.
⚡
Typed Error Handling
StripeConnectionError → 503 (retry safe). StripeInvalidRequestError → 400 (don't retry).
